# Dashboard screenshots

No screenshot images are included. Browser automation opened the earlier local Executive Overview, but saving screenshots to the project was blocked by the browser-control policy. No mockups or placeholder images are used.

## Manual capture instructions

1. From the project directory, install dependencies and run `streamlit run app.py`.
2. Open the local URL printed by Streamlit, maximize the browser, and use a consistent viewport (for example 1440 x 900 at 100% zoom).
3. Wait until each Plotly chart finishes rendering. Use the operating system screenshot tool to capture the browser content, then save each PNG in this folder.
4. Select each sidebar workspace and capture these actual application views:

   - `01_executive_overview.png`
   - `02_supply_chain_intelligence.png`
   - `03_sales_availability.png`
   - `04_search_discoverability.png`
   - `05_platform_ordering_gaps.png`
   - `06_action_centre.png`

5. Check that the selected page, chart labels, tables, and reporting dates are visible before saving.
